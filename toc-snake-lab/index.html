TOC Snake Lab

Six faithful fake-post demos for the left rail snake

These pages reuse your current post layout vocabulary and typography so you can judge the snake motion in something that feels close to the real site, without touching production.

Run a local server from the repo root, then open this folder and flip between the variants.

01 Current Closest recreation of the production segmented snake. 02 Low-Risk Tune Same segmented idea, but with cached metrics and softer motion. 03 Medium Upgrade One real snake element moving with transform, instead of many little pieces. 04 Single / Short Same single-element snake on a compact article so you can inspect the taller viewport-share behavior. 05 Single / Long Same single-element snake on a much longer article so the bar should become noticeably shorter. 06 Max Smooth Single snake plus spring smoothing for the most obviously buttery pass. 07 Line Alignment Static side-by-side tests for the black snake and grey TOC rail edge.
